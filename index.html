How to play

  1. Download the latest patch, rc Grass v2, from GitHub or Hackdex. It is a BPS patch file, not a ROM.
  2. Apply the patch to a clean Pokemon Emerald ROM you already own, using a BPS patcher.
  3. Play the patched game on a GBA emulator or a handheld.

Patches only, no ROMs. Fantasma does not provide a ROM.

New to patching? The GitHub releases page has the patch files. If you get stuck, ask on Instagram at @fantasmaromhack and I will help.

About the game

Fantasma is Italian for ghost. I am Don Duskull, a Pokemon fan since the 90s and a big Gengar fan. I spent six months building, designing, making maps in Porymap, and playtesting Fantasma start to finish.

On AI use, plainly: AI tools helped write scripts and most of the code, drafted dialogue I directed and edited, and painted battle backgrounds, menus, and new art. The idea, design, maps, balance, and playtesting are my work, and the dialogue in rc Grass v2 was rewritten by hand. I disclose this because players deserve to know how the game was made.

Built on pokeemerald-expansion. Releases are BPS patches, no ROMs.
